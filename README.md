# pg-yassinesabri-shl-commerce-hub

The hub of the Larder commerce estate: the shop where a customer picks this week's recipes and
places an order. It holds the requirements, stories and designs for three repositories,
`pg-yassinesabri-shl-storefront-web`, `pg-yassinesabri-shl-catalogue-api` and `pg-yassinesabri-shl-orders-api`, and no application code. `pg-yassinesabri-shl-catalogue-api` and
`pg-yassinesabri-shl-orders-api` are shared with the BAU team: the harness trunk is `bcg_main`, and the BAU team keeps
`main`.

- `docs/architecture/`: the estate's decision records. Each one binds every repository listed here.
- `docs/standards/`: the engineering standards a design and its code follow.
- `docs/estate/overview.md`: what the estate is, part by part.

The work-item keys carry the prefix `SHOP`.
